# TIME RUNNER

## Descripción

Time Runner es un videojuego 2D de plataformas y desplazamiento automático en el que el jugador controla a Jake, un viajero temporal capaz de alternar entre tres épocas distintas: Pasado, Presente y Futuro.

El objetivo es recorrer el nivel, superar obstáculos, evitar enemigos y utilizar los viajes en el tiempo para adaptarse a los diferentes escenarios y completar la aventura.

## Mecánicas Principales

### Movimiento

* Carrera automática.
* Salto.
* Sistema de gravedad.

### Viajes Temporales

* Cambio instantáneo entre:

  * Pasado
  * Presente
  * Futuro
* Cada era dispone de su propio escenario, enemigos y obstáculos.

### Sistema de Vidas

* 15 vidas disponibles.
* Respawn al inicio del nivel.
* Invulnerabilidad temporal tras recibir daño.
* Pantalla de Game Over cuando se agotan las vidas.

Guiar a Jake a través de las distintas épocas temporales, superar los desafíos del recorrido y completar el nivel utilizando estratégicamente los cambios entre Pasado, Presente y Futuro.
